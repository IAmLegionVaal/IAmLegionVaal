## Documentation rule

Each completed lab now records:

1. The issue or unexpected result encountered.
2. The corrective action performed.
3. The validation repeated after the change.
4. The final working outcome and findings.

Automated repair is only claimed where a real repair file exists. The remaining labs document the manual remediation performed during the completed project.

**This was tested by me to be working. User experience may vary.**
