## 🚀 Featured Project

# Windows Enterprise Troubleshooter

A menu-driven PowerShell toolkit for common Windows, Microsoft 365, OneDrive, networking, printer and endpoint issues.

**Built for real-world IT support.**

✅ Windows diagnostics  
✅ Microsoft 365 repair tools  
✅ OneDrive reset and recovery  
✅ Network troubleshooting  
✅ Printer diagnostics  
✅ Endpoint health checks  
✅ Logs and evidence collection  
✅ Helpdesk-friendly menu system  

> Goal: help IT teams troubleshoot faster and standardize support workflows.
